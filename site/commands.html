Giveaways

Run and manage giveaways.

Start a timed giveaway in the current channel.

!gstart 1h 1 Nitro

End an active giveaway before its timer runs out.

!gend 1234567890

List active giveaways in this server with time remaining.

Pick new winners for an ended giveaway.

!greroll 1234567890

Greetings

Configure welcome messages. Variables: {mention} pings the member, {username} is their name as plain text.

Toggle the current channel as a greeting channel.

Set a custom greeting message.

!greet set Welcome {mention}!

Auto-delete greeting messages after a duration.

!greet time 10s

FAQ

Quick answers to common questions.

What permissions does the bot need?

Send Messages, Embed Links, Read Message History and Add Reactions. Greeting auto-delete also needs Manage Messages.

Why can't members join the giveaway?

Check that the bot has Add Reactions and Read Message History in the channel where the giveaway runs.

Why doesn't the bot respond to commands?

Check three things: the bot's role position in your role list, its Send Messages permission in that channel, and that you're using the ! prefix.

How do I set a custom greeting?

Use !greet set <message>. Add {mention} to ping the member or {username} for their name. Example: !greet set Hey {mention}, welcome!

Can I use multiple greeting channels?

Yes. Run !greet in each channel to turn it on, and again to turn it off.

How do I test my greeting?

Run !greet test to send a test greeting with your current settings.

Can a giveaway have multiple winners?

Yes. Set the number in !gstart. For example, !gstart 2h 3 Nitro picks 3 winners after 2 hours.

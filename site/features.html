Features

Everything you need to run clean giveaways and welcome members, and nothing extra.

Giveaways

Reaction entry

Members join by reacting with 🎉, a format everyone already knows.

Random winners

Winners are picked at random from all valid entries.

Flexible duration

Set seconds, minutes or hours. The bot handles the countdown.

Manual end

Close any active giveaway early with !gend.

Giveaway list

See every active giveaway in the server and its time remaining.

Reroll

Pick new winners for an ended giveaway in one command.

Greetings

Custom messages

Write your own welcome text for each new member.

Multiple channels

Run !greet in each channel you want to toggle on or off.

Auto-delete

Remove greeting messages after a duration you choose, to keep channels tidy.

Variables

Use {mention} to ping the member or {username} for their name as plain text.

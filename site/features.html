Features

Built for simplicity.

Everything you need to run clean giveaways and smart greetings — nothing extra.

Giveaways

Powerful where it counts.

🎉

Reaction Entry

Members join by reacting with 🎉. A format everyone already knows — no learning curve.

🏆

Winner Selection

Truly random winner selection from all valid entries. Fair and transparent every time.

⏹️

Manual End

Need to end early? Use !gend to close any active giveaway instantly.

📋

Giveaway List

View all active giveaways in your server along with time remaining for each.

🔄

Reroll Winners

When a winner doesn't claim, reroll in one command. No need to restart anything.

⚙️

Flexible Duration

Set any duration — seconds, minutes, hours. The bot handles the countdown automatically.

Greeting System

Welcome members your way.

✏️

Custom Messages

Write your own welcome text with personalization variables for each new member.

📣

Multiple Channels

Toggle greeting delivery across as many channels as you need — run !greet per channel.

🗑️

Auto-Delete

Keep channels clean by auto-deleting greeting messages after a set duration.

Available Variables

Personalize greetings with: {mention} — pings the new member  ·  {username} — their display name

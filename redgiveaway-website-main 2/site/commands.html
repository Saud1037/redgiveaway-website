Command Reference

All available commands, their arguments, and usage examples.

Giveaway Commands

Run and manage giveaways.

Command Description Example
!gstart <time> <winners> <prize> Start a new timed giveaway in the current channel. !gstart 1h 1 Nitro
!gend <message_id> Manually end an active giveaway before its timer runs out. !gend 1234567890
!glist List all active giveaways in this server with time remaining. !glist
!greroll <message_id> Pick new winner(s) for an already-ended giveaway. !greroll 1234567890
Greeting Commands

Configure welcome messages.

Command Description Example
!greet Toggle the current channel as a greeting channel (on/off). !greet
!greet set <message> Set a custom greeting message. Supports variables. !greet set Welcome {mention}!
!greet time <duration> Auto-delete greeting messages after a specified duration. !greet time 10s
!greet reset Remove all channels marked as greeting channels. !greet reset
!greet clear Wipe all greeting settings for this server. !greet clear
!greet test Send a test greeting message to verify your configuration. !greet test
!greet stats Show the current greeting configuration for this server. !greet stats

Greeting Variables

Use these placeholders in your greeting message text:
{mention} — mentions (pings) the new member  ·  {username} — their username as plain text
